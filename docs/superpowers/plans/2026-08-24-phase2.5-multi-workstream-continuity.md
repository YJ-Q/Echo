# Margin Phase 2.5 Multi-Workstream Continuity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the first public, daily-usable Margin Workbench that safely switches among multiple Workstreams, restores an evidence-backed Resume Brief, reviews Candidate/Active/Archive Memory, and confirms stale-write conflicts.

**Architecture:** Extend the existing Persistent Core and transport-neutral Application Contract without changing the `execute`, `query`, and `events` Gateway methods. Add one reversible Memory lifecycle migration, application services for Memory, Resume Brief, and host-owned switching, then compose them into the existing React Workbench. Pi remains optional phrasing/runtime infrastructure; deterministic Core facts remain usable when Pi is unavailable.

**Tech Stack:** Node.js ESM >=22.19.0, SQLite, `node:test`, React 19, JSDOM 26, Vite 7, Pi Agent `0.84.2`, plain JavaScript/JSX and CSS.

## Global Constraints

- Execute from a fresh isolated worktree created from `eefc2cf` on branch `codex/phase2.5-continuity`.
- Read `docs/superpowers/specs/2026-08-24-phase2.5-multi-workstream-continuity-design.md` before Task 1.
- Persistent Core and `data/terminal-pilot/margin-core.sqlite` remain the only V1 Source of Truth.
- Every Surface uses only `execute(command)`, `query(query)`, and `events(query)` for durable behavior.
- Advance `CONTRACT_VERSION` exactly from `1.0` to `1.1`; preserve every Phase 2B route, envelope, command, query, and DTO field.
- Add no runtime or development dependency.
- Do not import the legacy app, routes, services, or `src/storage/memoryStore.js` into the V1 path.
- Pi Session ids remain runtime references and never become Workstream or Memory identity.
- Candidate Memory never participates in confirmed recall or blocking decisions.
- Archive is reversible retention through `archived_at`; do not use `deleted_at` to simulate archive.
- Workstream selection is read-only navigation. Only `workstream.switch` may coordinate source pause/checkpoint before target preparation.
- `workstream.switch` never starts or resumes the target Run.
- No raw prompt, conversation transcript, Chain of Thought, Pi object, credential, or source Session id crosses the Contract.
- Browser state remains disposable view state; do not add localStorage, IndexedDB, a browser database, or a domain cache.
- Use TDD for every production change: focused RED, minimal GREEN, focused regression, then commit.
- Stop and revise the approved spec before adding Personal Model, Feishu, Scheduler, Shared Workspace, arbitrary filesystem access, persistent Conversation, a suggestion table, a daily-plan table, or another database.

- [ ] **Step 4: Implement and compose WorkstreamSwitchService**

Validate both Workstreams and the source Run before pausing. Require source Run status `running`, require its `workstreamId` to equal `sourceWorkstreamId`, pause through `runs.pause`, record switch replay only after pause succeeds, then build the target brief. Never call `activate`, `start`, or `resume`.

```js
async function switchWorkstream(input, actor, runtimeControl) {
  authorize(actor);
  const replay = await repository.findSwitchReplay(input, actor);
  if (replay) return { sourceRun: await runs.get(replay.sourceRunId), targetBrief: await resumeBriefs.get({ workstreamId: input.targetWorkstreamId }) };
  const sourceRun = await runs.get(input.sourceRunId);
  if (!sourceRun || sourceRun.workstream_id !== input.sourceWorkstreamId) throw new CoreContractError('cross_workstream_reference', 'Source Run does not belong to source Workstream');
  const target = await repository.getWorkstream(input.targetWorkstreamId);
  if (!target) throw new CoreContractError('not_found', 'Target Workstream not found');
  const paused = await runs.pause({ requestId: pauseRequestId(input), runId: input.sourceRunId, expectedVersion: input.expectedVersion }, actor, runtimeControl);
  await repository.recordSwitchResult(input, actor, paused.data.id);
  return { sourceRun: paused.data, targetBrief: await resumeBriefs.get({ workstreamId: input.targetWorkstreamId }) };
}
```

```js
export function createConflict(value) {
  const keys = ['entityLabel', 'originalValue', 'currentValue', 'proposedValue', 'currentVersion'];
  if (!value || Object.keys(value).some((key) => !keys.includes(key)) || !Number.isInteger(value.currentVersion)) {
    throw new TypeError('invalid_conflict');
  }
  return Object.freeze(Object.fromEntries(keys.map((key) => [key, value[key]])));
}
```
