# Margin 中英文术语表

| 中文 | 英文 | 使用说明 |
|---|---|---|
| 第二自我 | second self | 表达持续理解关系，不写 digital twin |
| 到场 | arrival | 指用户无需整理即可进入，不写 onboarding |
| 当前仍然鲜活的线 | live line | 首次出现时解释为 what still matters now |
| 痕迹 | trace | 指被选择性保留、可继续的内容 |
| 选择性记忆 | selective memory | 强调相关性而非存储数量 |
| 继续 | continuation | 表达从上次痕迹接续，不等同 task completion |
| 接住 | receive / hold | 依语境选择，避免机械使用 catch |
| 页边批注 | margin note | 表达轻量建议，不写 instruction |
| 反思 | reflection | 避免 diagnostic analysis |
| 已实现 | implemented | 代码或可执行流程直接支持 |
| 已通过场景验证 | scenario-validated | 测试或功能场景支持，不代表真实用户价值 |
| 假设 | hypothesis | 仍需外部用户或市场验证 |

## 术语上下文例句

| 英文术语 | 中文例句 | English example |
|---|---|---|
| second self | Margin 是一个帮助用户保留重要线索的第二自我空间，而不是复制用户的数字孪生。 | Margin is a second-self space that preserves relevant threads; it is not a digital replica of the user. |
| arrival | 到场意味着用户不需要先整理成一个完整问题，也可以开始表达。 | Arrival means the user can begin without first organizing the moment into a complete problem. |
| live line | 当前仍然鲜活的线，是此刻仍然重要、仍在影响用户的内容。 | A live line is what still matters and remains active for the user now. |
| trace | 反思留下的是可被带回的过程痕迹，而不是对用户价值的评分。 | Reflection leaves a trace that can be returned to, not a score of the user’s worth. |
| selective memory | 选择性记忆优先保留会改变未来回应方式的内容，而不是储存每一句话。 | Selective memory retains what can improve a future response rather than storing every sentence. |
| continuation | 继续是从上一次留下的痕迹接续，不等同于完成一项任务。 | Continuation resumes from a previous trace; it is not the same as task completion. |
| margin note | 下一步以页边批注出现：清楚、轻量，而且可以被拒绝。 | The next step appears as a margin note: clear, lightweight, and rejectable. |
| scenario-validated | 已通过场景验证表示预设路径能够按规则运行，不表示真实用户价值已经成立。 | Scenario-validated means a predefined path worked under its rules; it does not establish real user value. |
